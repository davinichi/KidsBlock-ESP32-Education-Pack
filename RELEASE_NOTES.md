# Release Notes

## KidsBlock ESP32 Education Pack v0.1 Preview

**Release Date:** 2026-07-29

Welcome to the first public preview of the **KidsBlock ESP32 Education Pack**.

This project provides libraries, sample programs, and educational resources for IoT programming with ESP32 and KidsBlock. It is designed to support programming education in elementary schools, junior high schools, high schools, STEM activities, and maker projects.

---

## ✨ Included in this Release

### Libraries
- Environment Library
- NTPClock Library
- ThingSpeak Library
- Wi-Fi Library

### Documentation
- README
- LICENSE (MIT)
- CHANGELOG
- VERSION information

### Samples
- ESP32 sample programs
- Educational examples
- Installation package
