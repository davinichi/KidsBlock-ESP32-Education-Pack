# KidsBlock ESP32 Education Pack v0.2 Preview

本バージョンでは、KidsBlockとESP32で拡張機能を活用するための実践的なサンプルプログラムを追加しました。

## 新しいサンプルプログラム

- DHT11温湿度センサを使用したWBGTの計算・表示
- NTP Clockによる現在の日付と時刻の表示
- ThingSpeakへのデータ送信（Write）
- ThingSpeakからのデータ取得（Read）
- HTMLサーバを利用した環境モニター

## 収録拡張機能

- Environment
- NTP Clock
- ThingSpeak
- Wi-Fi

## ドキュメント

- 日本語・英語のREADME
- 日本語・英語のインストールガイド
- 学習・評価用サンプルプログラム

## プロジェクトの目的

KidsBlock ESP32 Education Packは、KidsBlockを使ったESP32プログラミング教育を支援するための拡張パッケージです。

センサ、ネットワーク、クラウドサービス、Webによるモニタリングなどを、実践的なサンプルを通して児童・生徒や教育関係者が学べるように設計しています。

本リリースは、教育利用における評価・試用を目的としたプレビュー版です。
