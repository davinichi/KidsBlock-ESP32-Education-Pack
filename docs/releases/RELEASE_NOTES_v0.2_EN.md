# KidsBlock ESP32 Education Pack v0.2 Preview

This preview release introduces practical sample programs that demonstrate how to use the included extensions with KidsBlock and ESP32.

## New Sample Programs

- WBGT calculation and display using the DHT11 temperature and humidity sensor
- Current date and time display using the NTP Clock extension
- Sending data to ThingSpeak (Write)
- Reading data from ThingSpeak (Read)
- Environmental Monitor using the built-in HTML server

## Included Extensions

- Environment
- NTP Clock
- ThingSpeak
- Wi-Fi

## Documentation

- English and Japanese README files
- English and Japanese installation guides
- Sample programs for learning and evaluation

## Purpose

KidsBlock ESP32 Education Pack is designed to support ESP32 programming education using KidsBlock.

Through practical examples and IoT applications, the project helps students and educators learn how to use sensors, networks, cloud services, and web-based monitoring with ESP32.

This is a preview release intended for evaluation and educational use.

Feedback, bug reports, and suggestions are welcome.
