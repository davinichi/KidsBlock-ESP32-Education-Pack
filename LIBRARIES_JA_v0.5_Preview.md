# LIBRARIES_JA

## KidsBlock ESP32 Education Pack Version 0.5 Preview

本書は Education Pack
に収録されている各ライブラリの目的と主な用途をまとめたガイドです。

------------------------------------------------------------------------

# Communication

## WiFi Simple

**目的**：ESP32をWi-Fiへ接続します。

**主な用途** - 無線LAN接続 - HTTP ServerやThingSpeakの利用

------------------------------------------------------------------------

## HTTP Server

**目的**：ブラウザからESP32の状態を表示・操作します。

**主な用途** - センサー値表示 - ON・OFFボタン - ラジオボタン -
スマートフォン・PCからの監視

------------------------------------------------------------------------

## ThingSpeak

**目的**：ThingSpeakとのデータ送受信を行います。

**主な用途** - センサーデータ保存 - グラフ表示 - クラウド連携

------------------------------------------------------------------------

## BLE UART 3

**目的**：Bluetooth Low Energy通信を行います。

**主な用途** - スマートフォン連携 - Chromebookとの通信 -
シリアルデータ送受信

------------------------------------------------------------------------

## ESP-NOW ESP32

**目的**：ESP32同士を高速・低消費電力で通信します。

**主な用途** - センサーネットワーク - ブロードキャスト通信 - 1対1通信

------------------------------------------------------------------------

# Other

## Environment

**目的**：環境データの計算を行います。

**機能** - WBGT - 湿球温度 - 暑さ指数

------------------------------------------------------------------------

## NTP Clock

**目的**：インターネットから日時を取得します。

**主な用途** - 時計 - タイムスタンプ - データ記録

------------------------------------------------------------------------

## KBSD ESP32

**目的**：microSDカードを利用します。

**機能** - ファイル保存 - ファイル読込 - CSV保存 - ログ記録

------------------------------------------------------------------------

## Data Processing

**目的**：データや文字列を処理します。

**機能** - 文字列結合 - 区切り文字結合 - 文字列長 - 部分文字列取得 -
CSV文字列処理

------------------------------------------------------------------------

## ESP32 System Information

**目的**：ESP32の情報を取得します。

**取得できる情報** - MACアドレス - チップモデル - CPU周波数 -
フラッシュ容量 - ヒープメモリ - SDKバージョン

------------------------------------------------------------------------
