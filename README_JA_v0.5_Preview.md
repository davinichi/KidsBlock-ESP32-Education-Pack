# KidsBlock ESP32 Education Pack

## Version 0.5 Preview

**ESP32プログラミング教育のための統合開発パッケージ**

## 概要

KidsBlock ESP32 Education Pack
は、ESP32を利用したプログラミング教育を支援する統合開発パッケージです。

温湿度センサやLEDなどを利用した電子工作から、Wi-Fi、BLE、ESP-NOW、クラウド通信まで、IoT学習に必要な機能をKidsBlockのブロックプログラミングで学ぶことができます。

生成されるプログラムはArduino
C++コードであり、ブロックプログラミングから本格的なプログラミングへ段階的に学習を進めることができます。

## 主な特長

-   ESP32専用の教育向け統合開発パッケージ
-   Arduino C++コードを自動生成
-   通信・クラウド・データ処理を幅広くサポート
-   教育現場での利用を重視した設計

## 収録ライブラリ（10種類）

### Communication

-   WiFi Simple
-   HTTP Server
-   ThingSpeak
-   BLE UART 3
-   ESP-NOW ESP32

### Other

-   Environment
-   NTP Clock
-   KBSD ESP32
-   Data Processing
-   ESP32 System Information

## 動作環境

-   Windows 10 / 11
-   KidsBlock Desktop
-   ESP32 Arduino Core 3.2.0
-   ESP32シリーズ

## 開発方針

「教育現場で安心して利用できるESP32教材」を目標として、安定性・互換性・分かりやすさを重視して継続的に改善しています。
