# KidsBlock ESP32 Education Pack

## Version 0.5 Preview

**ESP32プログラミング教育のための統合開発パッケージ**

------------------------------------------------------------------------

# 1. Education Packとは

KidsBlock ESP32 Education Pack
は、ESP32を利用したプログラミング教育を支援する統合開発パッケージです。

センサー、表示装置、データ保存、ネットワーク通信、クラウドサービスまでを
ブロックプログラミングで扱えるように設計されています。

生成されるプログラムは Arduino C++ コードであり、
ブロックからテキストプログラミングへの橋渡しにも適しています。

------------------------------------------------------------------------

# 2. Education Packのコンセプト

教育現場で利用しやすいことを第一に考えています。

-   分かりやすいブロック
-   安定した動作
-   IoT教材を短時間で製作可能
-   Arduino C++へ発展可能

------------------------------------------------------------------------

# 3. IoT教材の流れ

    センサー
       ↓
    データ処理
       ↓
    保存
       ↓
    通信
       ↓
    表示・活用

Education Pack はこの一連の流れをすべて学習できます。

# 5. 収録ライブラリ（10種類）

## Communication

  ライブラリ      概要
  --------------- --------------------
  WiFi Simple     Wi-Fi接続
  HTTP Server     ブラウザ監視・操作
  ThingSpeak      クラウド通信
  BLE UART 3      BLE通信
  ESP-NOW ESP32   ESP32間通信

## Other

  ライブラリ                 概要
  -------------------------- ------------------
  Environment                WBGTなど環境計算
  NTP Clock                  日時取得
  KBSD ESP32                 microSD
  Data Processing            CSV・文字列操作
  ESP32 System Information   ESP32情報取得
