## Extensions

### Communication

| Path | Display name |
|---|---|
| `extensions/other/wifisimple` | WiFi Simple |
| `extensions/other/httpserver` | HTTP Server |
| `extensions/other/thingspeak` | ThingSpeak |
| `extensions/other/bleuart3` | BLE UART 3 |
| `extensions/other/espnow_esp32` | ESP-NOW ESP32 |

### Other

| Path | Display name |
|---|---|
| `extensions/other/environment` | Environment |
| `extensions/other/ntpclock` | NTP Clock |
| `extensions/other/kbsd_esp32` | KBSD ESP32 |
| `extensions/other/kbcsv_esp32` | Data Processing |
| `extensions/other/esp32_system_info` | ESP32 System Information |

The physical extension folders are stored under `extensions/other`. KidsBlock display categories are determined by each extension's `tags` setting.
