# KidsBlock ESP32 Education Pack

## Version 0.6 Preview

**An integrated development package for ESP32 programming education**

KidsBlock ESP32 Education Pack provides educational extensions for sensors, data processing, storage, Wi-Fi, BLE, ESP-NOW, browser control, and cloud communication.

The blocks generate Arduino C++ code and are designed to support a gradual transition from block programming to text-based programming.

## Included libraries

### Communication

- WiFi Simple
- HTTP Server
- ThingSpeak
- BLE UART 3
- ESP-NOW ESP32

### Sensor

- BME280

### Display

- LCD1602 Symbols

### Other

- Environment
- NTP Clock
- KBSD ESP32
- Data Processing
- ESP32 System Information

## Environment

- Windows 10 / 11
- KidsBlock Desktop
- ESP32 Arduino Core 3.2.0
- ESP32 / ESP32-S3
