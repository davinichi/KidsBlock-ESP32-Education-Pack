# INSTALL_JA

## KidsBlock ESP32 Education Pack Version 0.5 Preview

このガイドでは、KidsBlock ESP32 Education Pack
のインストール方法を説明します。

------------------------------------------------------------------------

# 1. 動作環境

-   Windows 10 / Windows 11
-   KidsBlock Desktop
-   ESP32 Arduino Core 3.2.0

------------------------------------------------------------------------

# 2. インストール前の確認

-   KidsBlock を終了してください。
-   インターネット接続は不要です。
-   管理者権限を持つユーザーで実行することを推奨します。

------------------------------------------------------------------------

# 3. インストール手順

1.  配布された ZIP ファイルを展開します。
2.  展開したフォルダを開きます。
3.  `install.bat` を右クリックし、「管理者として実行」を選択します。
4.  インストールが完了するまで待ちます。

正常終了すると、次のようなメッセージが表示されます。

    Installation completed successfully.
    Installed 10 extensions.
    Version: 0.5-Preview

------------------------------------------------------------------------

# 4. インストールの確認

KidsBlock を起動し、「拡張機能」を開きます。

次の 10 ライブラリが表示されることを確認してください。

## Communication

-   WiFi Simple
-   HTTP Server
-   ThingSpeak
-   BLE UART 3
-   ESP-NOW ESP32

## Other

-   Environment
-   NTP Clock
-   KBSD ESP32
-   Data Processing
-   ESP32 System Information

------------------------------------------------------------------------

# 5. 最初の動作確認

以下の順で確認することをおすすめします。

1.  LED点滅プログラム
2.  Environment
3.  HTTP Server
4.  ThingSpeak
5.  ESP-NOW

------------------------------------------------------------------------

# 6. アンインストール

展開したフォルダ内の `uninstall.bat` を実行してください。

------------------------------------------------------------------------

# 7. トラブルシューティング

## ライブラリが表示されない

-   KidsBlock を再起動してください。
-   install.bat を再実行してください。

## インストールに失敗する

-   KidsBlock が起動していないことを確認してください。
-   セキュリティソフトがブロックしていないか確認してください。

## PowerShell の実行エラー

ダウンロードしたファイルを右クリックし、「プロパティ」→「許可する」をチェックするか、PowerShellで次を実行してください。

    Unblock-File .\make_release.ps1

------------------------------------------------------------------------

# 8. 更新

新しいバージョンをインストールする場合は、再度 `install.bat`
を実行してください。
既存のライブラリは新しいバージョンで上書き更新されます。

------------------------------------------------------------------------
