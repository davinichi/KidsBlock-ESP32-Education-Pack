LCD1602 Symbols v1.0.0
Author: davinichi

Reusable LCD1602 custom-symbol blocks for KidsBlock ESP32 Education Pack.

Blocks:
- Register LCD1602 custom symbols
- Degree Celsius symbol (℃)
- g/m³ symbol (uses two character cells)

Usage notes:
- Use an LCD1602 initialization block first so the generated program has an object named "lcd".
- Run "register LCD1602 custom symbols" once during setup before displaying the symbols.
- Custom character slots 5, 6 and 7 are used.
