Environment Ver.1.6.0 - LCD1602 special symbol revision

Changes
- Added command block: "LCD1602特殊記号を登録".
- The command block registers CGRAM characters 5, 6 and 7 using the existing standard KidsBlock lcd object.
- Removed automatic createChar() calls from the ℃ and g/m3 data blocks.
- No I2C address, lcd.begin(), lcd.backlight() or cursor setting is generated by Environment.
- Cursor coordinates remain entirely controlled by the standard LCD1602 blocks (0,0 origin).
- Revised 5x8 dot patterns for ℃ and the two-cell g/m3 symbol.

Required block order
1. Standard LCD1602 initialization block
2. Environment "LCD1602特殊記号を登録" block (once)
3. Standard LCD1602 display blocks using the Environment ℃ or g/m3 data blocks

Important
- The register block must execute after lcd.begin().
- CGRAM slots 5, 6 and 7 are used.
