HTTP Server ESP32 Ver.3.3.1

主な機能
- 表示項目 最大8件
- 独立したON・OFFボタン 最大8系統
- ラジオボタン 1グループ・最大8項目
- ラジオボタンの選択番号（0～8）を取得
- ラジオボタンの選択状態を六角形の条件ブロックで判定

GPIOやサーボの実際の制御にはKidsBlock標準ブロックを使用してください。
新しいクラス名 SensorServer32 を使用し、旧版のビルドキャッシュとの混在を防ぎます。

Ver.3.3.1の画面表示
- 表示項目が0件の場合、「表示データ」領域を非表示
- ON・OFFボタンが0件の場合、その領域を非表示
- ラジオボタンが0件の場合、その領域を非表示
- 通信状態は常に表示

全面整理版
- バージョン表示をSENSOR_SERVER32_VERSIONへ一元化
- ブラウザキャッシュ抑止を強化
- 更新タイマーのJavaScript生成を修正
- 未登録セクションはhidden属性で非表示
- 通信状態は常時表示
