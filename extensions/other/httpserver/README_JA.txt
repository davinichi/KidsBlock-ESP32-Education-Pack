HTTP Server ESP32 Ver.3.1.2.2

主な機能
・ブラウザに最大8項目の値を表示
・最大4系統のブラウザ操作を登録
・各操作の2つのボタン名を自由に設定
・ブラウザ操作の状態をHIGH／LOWとして取得

基本的な使い方
1. Wi-Fiへ接続します。
2. ブラウザ操作を登録します。
   例：名前「LED」、HIGHボタン「点灯」、LOWボタン「消灯」
3. HTTPサーバーを開始します。
4. ループ内で「ブラウザからのアクセスを処理する」を実行します。
5. 「ブラウザ操作1はHIGH／LOW」を条件にし、KidsBlock標準のピンブロックで出力を制御します。

設計方針
HTTP Serverはブラウザ操作の状態を保持します。GPIOのOUTPUT設定やHIGH／LOW出力はKidsBlock標準ブロックで行います。

非表示ブロック
Ver.3.0との互換性のため、「ブラウザ操作の出力を変更する」「ブラウザ操作を消去する」の内部定義は残していますが、ツールボックスには表示しません。
