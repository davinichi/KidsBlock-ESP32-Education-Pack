ESP32システム情報 Ver.1.1.2

ESP32 / ESP32-S3の各種システム情報を、個別の丸形の値ブロックとして取得するKidsBlock拡張です。
シリアルモニター、LCD、HTTP Server、SDカード、ESP-NOWなど、任意の出力先と組み合わせて使用できます。

公開ブロック:
- チップモデル
- チップリビジョン
- CPUコア数
- CPU周波数
- Arduino ESP32 Coreバージョン
- ESP-IDFバージョン
- Wi-Fi MACアドレス
- フラッシュ容量・速度
- スケッチ使用容量・空き領域
- ヒープ総量・空き・最小空き・最大連続空き領域
- PSRAM容量・空き容量
- 稼働時間

容量はバイト、周波数はMHz、稼働時間は秒で返します。
Ver.1.0.0の一括シリアル表示ブロックは互換性のため内部に残していますが、ツールボックスには表示しません。

Ver.1.1.2では、KidsBlockの標準出力ブロックへ差し込みやすいよう、公開ブロックの形状をすべて丸形に統一しました。
