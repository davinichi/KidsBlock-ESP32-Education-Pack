# Installation Guide

# KidsBlock ESP32 Education Pack

Welcome!

This guide explains how to install the **KidsBlock ESP32 Education Pack** on Windows.

---

# System Requirements

Before installation, please ensure that the following software is already installed.

- Windows 10 / Windows 11
- KidsBlock Desktop
- Internet connection (recommended)

---

# Download

Download the latest release from the GitHub **Releases** page.

Extract the downloaded ZIP file to any folder.

Example:

```
KidsBlock-ESP32-Education-Pack-v0.1-Preview.zip
```

---

# Installation

1. Close KidsBlock Desktop.
2. Open the extracted folder.
3. Run `install.bat`.
4. Wait until the installation is complete.
5. Start KidsBlock Desktop.

---

# Verify the Installation

Open the **Extensions** panel.

Confirm that the following libraries are available.

- Environment
- NTPClock
- ThingSpeak
- Wi-Fi

If they are listed, the installation has completed successfully.

---

# First Test

1. Open one of the sample projects.
2. Connect your ESP32 board.
3. Upload the program.
4. If it runs successfully, your installation is complete.

---

# Updating

Download the latest release and run `install.bat` again.

The existing libraries will be updated automatically.

---

# Troubleshooting

## The blocks do not appear

- Restart KidsBlock.
- Run `install.bat` again.
- Verify that KidsBlock is installed correctly.

## Installation failed

- Run `install.bat` as Administrator.
- Make sure KidsBlock is closed before installation.

---

# Uninstall

If your release includes `uninstall.bat`, run it.

Otherwise, remove the installed Education Pack libraries manually.

---

# Support

If you encounter any problems, please open a GitHub **Issue**.

Please include the following information whenever possible:

- Windows version
- KidsBlock version
- ESP32 board model
- Error message
- Screenshot (if available)
